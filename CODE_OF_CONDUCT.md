# Code of Conduct

This project follows the **Contributor Covenant, version 2.1**:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In short: we pledge to make taking part in this project a harassment-free experience for
everyone, and we act and interact in ways that contribute to an open, welcoming, diverse,
inclusive and healthy community. Be respectful, give and accept constructive feedback
gracefully, and focus on what is best for the community.

## Scope

The Code of Conduct applies in all project spaces (issues, pull requests, discussions and any
other channel of this repository) and when someone represents the project in public.

## Enforcement

Report unacceptable behaviour privately to the maintainers through GitHub's
[private reporting](https://github.com/rennerdo30/agent-pair-programming/security/advisories/new) or by
contacting the repository owner, [@rennerdo30](https://github.com/rennerdo30). All complaints are reviewed
and investigated promptly and fairly, and the privacy and security of the reporter are respected.

Maintainers follow the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
(correction, warning, temporary ban, permanent ban) when deciding on consequences.
